# Neon Protocol – Android

Ovdje je samo gotova aplikacija za Android, ne i kod igre.

- `NeonProtocol.apk` – najnovija verzija igre
- `version.json` – broj verzije; aplikacija ga čita pri pokretanju i sama nudi ažuriranje

Instalacija prvi put: preuzmi `NeonProtocol.apk` na telefon, otvori ga i dozvoli instalaciju iz nepoznatog izvora.
Nakon toga se nove verzije nude same kad pokreneš igru.
